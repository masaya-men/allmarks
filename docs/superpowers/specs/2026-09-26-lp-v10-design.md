## 3. 作りの分担

```
lib/marketing/lp/            … 枠組みに依存しない TS(DOM を触るものは client 専用)
  types.ts                   … ArtKind / CardSpec / Pt などの共有型
  motion-math.ts             … clamp01 / eio / E / lerp / wp / isPress(純関数)
  masonry.ts                 … masonry(specs, order, W, cols, gap)(純関数)
  feature-timeline.ts        … featState(P, geo) → 描画値の plain object(純関数)
  art.ts                     … ART 描画群(halftone/halftone3/film/dither/truchet/swiss/ticker/arches/grid/rules/bars/vinyl/tag)と makeCard(spec, amb, tweetText)
  marquee.ts                 … 流れる帯(速度連動・画面外で停止)
components/marketing/
  LandingPage.tsx            … 構成のみ(Lenis 呼び出しを外す。data-theme/lang の既存処理は維持)
  BackgroundGrid.tsx(+css)  … 新規
  lp-art.css                 … カード・絵の CSS(art.ts が作る DOM 用。CSS Modules では名前が変わるため global。全セレクタを `.lpRoot` の下に限定)
  SiteHeader.tsx(+css)      … ワードマーク変更・CTA の文字が転がるホバー・`html[data-lp-finale]` で非表示
  sections/Hero.tsx          … 置き換え(intro 線・ヒーロー・スクロールの合図を含む)
  sections/Problem.tsx       … 置き換え
  sections/Tape.tsx          … 新規
  sections/Features.tsx      … 置き換え(6段)
  sections/FinalCta.tsx      … 締め(回る円)に置き換え(ファイル名は維持)
  sections/ShareIt.*         … 削除(06 に統合)
```

各 section は `'use client'`。`useEffect` の中で: 絵を1回描く → 寸法を測ってキャッシュ → ScrollTrigger / gsap.ticker / IntersectionObserver / resize を登録 → **cleanup で全部外す**(dev の StrictMode 二重実行で残骸が出ないこと)。

描画ループの規則(見本どおり):
- スクロール中・ticker 中に寸法を読まない(レイアウト時とリサイズ時だけ測る)
- 書き換えるのは transform / opacity / clip-path と、状態クラスの付け外しだけ
- 絵は1回だけ描く。例外は 03 の動画(128×72 を再生中のみ約24コマ/秒)
- 画面外の常時アニメは止める(`.is-off` → `animation-play-state: paused`)

`feature-timeline.ts` は見本 v10 の `renderFeat` の計算部分(seg/f の判定・各要素の値)を純関数に切り出したもの。DOM への適用は Features.tsx 側。これで「03 の f=.64 で MOTION が押される」「04 の f=.45 で music のカードだけ」「06 の f=.8 でコピー済み」などを単体テストで固定できる。

### 3.1 動きを減らす設定(prefers-reduced-motion: reduce)
見本の `motionOK=false` と同じ: intro なし・常時アニメなし・帯は止める・Features はなめらか追従なしで各段の完成形・動画は静止。

### 3.2 リンク先
- 「ボードを開く」系(ヒーロー・ヘッダー・05 の入口画面は見本の中の絵なのでリンクなし・締めの円・締めのボタン): 現行 Hero / FinalCta と同じ href を使う(実装時に現行コードから引き継ぐ)
- 「使い方を見る」: 現行 Hero と同じくボタン。押すと Features 区画の先頭へスクロール(動きを減らす設定ではアニメなし)

## 5. 書体(見出しに複数の書体が混ざらない)

- 見出し・本文・見本の中の文言は、**その言語の書体を先頭に置いたスタック**で描く。日本語の文中の英字も日本語書体で出る(1行の中で書体が混ざらない)。
- 英語固定のデザイン文字(§4.3)は別要素なので Geist / Geist Mono のまま。
- 言語別の先頭書体:
  - en de es fr it nl pt tr: Geist(next/font。latin-ext を含める)
  - ru: Geist の Cyrillic が読めればそれ、なければ Noto Sans
  - vi: Noto Sans(Geist は Vietnamese 非対応の見込み。実測で判断)
  - ja: Noto Sans JP / zh: Noto Sans SC / ko: Noto Sans KR
  - th: Noto Sans Thai(英字は Noto Sans)/ ar: Noto Sans Arabic(英字は Noto Sans)
- 読み込み: Next の font 機能で賄えない書体は Google Fonts CSS2 の `<link>`(既存の Yomogi と同じ方式・`display=swap`・可変ウェイト `wght@400..800`)を、**その言語のページでだけ**出す。
- **検証(自動)**: Playwright + CDP `CSS.getPlatformFontsForNode` で、15言語すべての見出し・本文の要素について、実際に使われた書体が1つ(th/ar は その言語の Noto + Noto Sans まで)であることを確認する。
